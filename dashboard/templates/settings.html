How to apply changes

  1. Save a var → it's written to agent/.env with chmod 600 immediately.
  2. The bot/judge daemons pick up env changes only on restart. For per-trade caps (MAX_SIZE, DAILY_LOSS_LIMIT), execute_live.py reads env on each call so they take effect for the next live trade.
  3. To pick up changes in the dashboard itself (this page), Ctrl+C and re-launch uvicorn.
